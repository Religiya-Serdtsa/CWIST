Detailed Description

Implementation of HTTP/3 protocol handler for CWIST.

This file implements an HTTP/3 server using OpenSSL's QUIC support. It manages the QUIC connection, accepts multiplexed incoming QUIC streams, parses basic HTTP/3 frames, and dispatches requests.
