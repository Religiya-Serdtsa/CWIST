Detailed Description

lsquic/BoringSSL-based HTTP/3 server for CWIST.

Implements a full HTTP/3 server using LiteSpeed's lsquic library linked statically against BoringSSL. Handles QUIC transport, QPACK, and HTTP/3 framing per RFC 9114.
