Starts serving an HTTP/2 connection over an established HTTPS session.

Processes HTTP/2 frames, decodes HPACK headers (minimal support for testing), triggers the appropriate user-defined request handler, and multiplexes the response back to the client. Works with both TLS (h2) and cleartext (h2c).

Parameters
connPointer to the HTTPS connection structure (ssl can be NULL for h2c).
user_ctxOpaque user context to pass to the handler.
handlerFunction pointer to the user's HTTP request handler.
Returns
cwist_error_t Structure indicating success or failure.
