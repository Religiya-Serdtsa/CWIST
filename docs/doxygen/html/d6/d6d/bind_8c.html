Bind a JSON payload to a user struct according to a schema.

The JSON body of req is parsed once and then each field in schema is extracted, validated, and written into out at the specified offset.

On validation failure the function returns false and populates result with per-field error messages. The caller can then pass result to cwist_bind_write_error_response() to emit a 400 response.

Parameters
reqHTTP request whose body contains the JSON payload.
schemaBind schema describing the target struct layout.
outPointer to the user struct to populate.
result[out] Detailed validation result.
Returns
true when every field passes validation and the struct is filled.

Convenience wrapper: bind JSON and auto-respond 400 on failure.

If binding succeeds, the function returns true and out is filled. If binding fails, the function automatically sets res to 400 Bad Request with a JSON error body and returns false.

Parameters
reqHTTP request.
resHTTP response (may be mutated on failure).
schemaBind schema.
outPointer to the user struct to populate.
Returns
true on success; false when res has been prepped with 400 errors.
