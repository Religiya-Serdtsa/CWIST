Detailed Description

Single field descriptor used by both the healer and the Zod validator.

aliases is a NULL-terminated list of alternative names that will be renamed to name during L2 alignment. Fuzzy (case-insensitive, separator-stripped) matching is applied when exact aliases do not match.
