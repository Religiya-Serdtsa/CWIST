Perform a synchronous HTTP request.

The request is executed using libcurl's easy interface. HTTP/2 multiplexing is used automatically when the server supports it. If Alt-Svc is enabled and the server previously advertised h3, libcurl may upgrade to HTTP/3 transparently.

Parameters
clientClient handle.
urlFully-qualified URL (e.g. "https://example.com/path").
methodHTTP method enum.
headersOptional request headers linked list (may be NULL).
bodyOptional request body (may be NULL).
body_lenLength of body in bytes.
out_responseOutput pointer for the parsed response. Caller must destroy with cwist_http_response_destroy().
Returns
CWIST error, err_i16 == 0 on success.
