Detailed Description

Low-latency io_uring backend for CWIST event loop integration.

Directly uses the Linux io_uring UAPI (via syscall) to avoid liburing dependency while retaining full control over SQ/CQ rings, fixed buffers, and multi-shot operations.

Design goals:

  • Lock-free submission when possible (SQPOLL opt-in).
  • Fixed buffers for hot-path networking to reduce TLB pressure.
  • Unified TCP/UDP sendmsg/recvmsg paths for HTTP/1–3.
