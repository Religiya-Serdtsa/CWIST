cwist_error_t cwist_https_send_response ( cwist_https_connection *  conn,
cwist_http_response *  res 
)

Serialize an HTTP response and send it over an active TLS connection.

Serialize an HTTP response and send it over the SSL connection. Streams the header block and body separately (zero-copy; no intermediate serialization blob) and supports pointer bodies and file streams.

Zero-copy counterpart of the plaintext send path: the header block is serialized into a stack buffer and written first, then the body is streamed straight from its origin (pointer body, sstring, or file stream) instead of materializing one contiguous heap blob.

Parameters
connActive HTTPS connection wrapper.
resResponse object to serialize.
Returns
Tagged CWIST error describing success or failure.
