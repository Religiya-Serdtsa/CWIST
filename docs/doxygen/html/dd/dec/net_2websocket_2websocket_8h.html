Receive a frame, blocking until data arrives or the socket closes.

Returns
NULL on error or if the connection was closed.

Receive a frame, blocking until data arrives or the socket closes.

Client frames are required to be masked by RFC 6455, so unmasked payloads are rejected. Payload data is copied into a heap buffer and null-terminated for convenience when the caller interprets a text frame as a C string.

Parameters
wsWebSocket connection wrapper returned by cwist_websocket_upgrade().
Returns
Newly allocated frame, or NULL when the connection is closed or invalid.

Receive and reassemble a sequenced binary message.

Reads binary frames until every chunk of one sequenced message has arrived, discarding duplicates and reordering out-of-order chunks. The returned buffer is heap-allocated and must be freed with cwist_free().

Parameters
wsWebSocket connection.
out_lenReceives the length of the reassembled payload.
Returns
Newly allocated payload buffer, or NULL on error/incomplete message.

)

Send a large payload as sequenced binary frames.

Splits data into chunks of chunk_payload_size (or smaller for the final chunk), prefixes each chunk with the CWIST sequence header, and sends every chunk as an independent binary frame. The peer can reassemble the original payload even when frames arrive out of order.

Parameters
wsWebSocket connection.
dataPayload bytes.
lenPayload length.
chunk_payload_sizeMaximum payload bytes per chunk (must be > 0).
Returns
0 on success, -1 on failure.

Upgrade a standard HTTP request to a WebSocket connection.

Upgrade a standard HTTP request to a WebSocket connection.

The function validates the required upgrade headers, computes the Sec-WebSocket-Accept response, emits the 101 Switching Protocols reply, and returns a lightweight wrapper around the already-open client socket.

Parameters

Returns
WebSocket wrapper on success, or NULL when the handshake fails.
