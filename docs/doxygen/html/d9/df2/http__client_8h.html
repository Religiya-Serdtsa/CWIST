Detailed Description

Unified HTTP/1.1 and HTTP/2 client using libcurl.

Provides a CWIST-native wrapper around libcurl for synchronous HTTP requests. Supports connection reuse, Alt-Svc upgrade to HTTP/3, redirects, cookies, and TLS via the system libcurl (linked against BoringSSL + nghttp2).
