void cwist_app_healthz ( cwist_http_response *  res)

Populate an HTTP response with the healthz JSON payload.

Status mapping:

  • 200 OK when overall == CWIST_HEALTH_OK
  • 503 Service Unavailable when overall == CWIST_HEALTH_FAIL or DEGRADED

JSON shape:

{"status":"ok","probes":[{"name":"database","status":"ok"},...]}
Parameters
resResponse to populate.
