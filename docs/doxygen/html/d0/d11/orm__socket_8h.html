cwist_orm_t * cwist_orm_open_socket ( int  sock)

Create an ORM session from an existing SQL socket.

The socket must have been produced by cwist_db_transfer_sqlite_to_socket() or by an equivalent SQL-socket factory. The ORM object takes ownership of socket_fd and will close it on cwist_orm_close_socket().

Parameters
socket_fdValid connected Unix socket file descriptor.
Returns
Pointer to an initialized cwist_orm_t, or NULL on allocation failure.
