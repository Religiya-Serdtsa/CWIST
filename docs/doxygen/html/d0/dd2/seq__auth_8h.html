Detailed Description

Authenticated v2 envelope for CWIST sequenced payloads.

The legacy eight-byte sequence header has no cryptographic binding. This opt-in envelope authenticates every fragment with HMAC-SHA-256, binds it to an application session, and keeps bounded nonce/message-id replay windows.
