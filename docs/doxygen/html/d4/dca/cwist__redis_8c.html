Authenticate/select a logical Redis database on this connection.

Warning
AUTH credentials are sent over plaintext TCP (RESP has no encryption by itself). Only use this over loopback, a trusted private network, or behind a TLS-terminating proxy (stunnel/spiped) in front of Redis.

◆ cwist_redis_subscribe()

cwist_error_t cwist_redis_subscribe ( cwist_redis_t *  r,
const char **  channels,
cwist_redis_msg_cb  cb,
void *  ctx 
)

Subscribe to channels on a dedicated connection.

This call blocks the current thread and invokes cb for each message. Use it inside a background thread. To stop, call cwist_redis_close() from another thread (the read loop will exit on socket error).

Parameters
rConnection. Must not be shared with other commands.
channelsNULL-terminated array of channel names.
cbMessage callback.
ctxUser context forwarded to callback.
Returns
0 when stopped cleanly, -1 on error.
