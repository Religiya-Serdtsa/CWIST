Split a JWT token into sequenced chunks.

The returned chunks can be transmitted out of order and reassembled with cwist_jwt_join_chunks(). This is useful when the token is too large for a single UDP datagram, WebSocket frame, or HTTP/2 DATA frame.

Parameters
tokenJWT string to split.
chunk_payload_sizeMaximum token bytes per chunk (must be > 0).
out_countReceives the number of chunks.
Returns
Array of chunk objects, or NULL on error. Caller must free with cwist_jwt_chunks_free().
