cwist_middleware_func cwist_mw_jwt_auth ( const char * secret)

JWT authentication middleware factory.

Reads the Authorization header, expects "Bearer <token>". On success the decoded claims are available via the request context. On failure responds with 401 Unauthorized and short-circuits the chain.

Parameters
secretHMAC-SHA256 signing secret (null-terminated, must outlive the middleware invocations — typically a static/global string).
Returns
Middleware function pointer.

JWT authentication middleware factory.

Parameters

Returns
